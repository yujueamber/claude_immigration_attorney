# NIW Narrative Review Skill

A strict NIW quality gate that complements the repository's existing Dhanasar knowledge and drafting skills.

Use it after evidence collection and during proposed-endeavor development, Prong mapping, narrative drafting, and RFE-risk review.

It is designed to catch:
- employer-benefit traps,
- generic proposed endeavors,
- unsupported broader-impact claims,
- team-vs-individual attribution errors,
- future results presented as completed,
- Prong 3 arguments that merely repeat Prong 1.
